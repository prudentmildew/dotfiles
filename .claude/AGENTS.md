# AGENTS.md

Local instructions for solo, agent-driven development. Project-specific instructions override this file.

## Scope

- Technology-agnostic by default.
- Each project defines its own stack and conventions.

## Workflow

1. Ideation – define the problem, feature, or refactor. Uses the `/ideate` skill.
2. Research – if exploration is non-trivial, create `research.md` to capture findings. Uses the `/research` skill.
3. Prototype – validate the approach with quick code or assets. Uses the `/prototype` skill.
4. PRD – write requirements, user stories, and implementation notes. Uses the `/prd` skill.
5. Kanban – split the PRD into tickets with dependencies. Uses the `/kanban` skill.
6. Execution – implement tickets iteratively with coding agents. Uses the `/execute` skill.
7. QA – write a human test plan. Uses the `/qa` skill.
