# AGENTS.md

Local instructions for solo, agent-driven development. Project-specific instructions override this file.

## Scope

- Technology-agnostic by default.
- Each project defines its own stack and conventions.

## Workflow

1. Ideation — define the problem, feature, or refactor.
2. Research — if exploration is non-trivial, create `research.md` to capture findings.
3. Prototype — validate the approach with quick code or assets.
4. PRD — write requirements, user stories, and implementation notes.
5. Kanban — split the PRD into tickets with dependencies.
6. Execution — implement tickets iteratively with coding agents.
7. QA — write a human test plan.
